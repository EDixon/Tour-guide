Prompt builder
✕
Builds exactly the prompt the assistant would send, using the same code and knowledge files as the app. Questions in a conversation carry on from each other, as they will in the app.

Paste into a new chat in AI Edge Gallery.

Code: assistant/prompt.mjs, retrieve.mjs, maths.mjs. Knowledge: knowledge/wrest-park-sample.md and wrest-park-dates.json. Only the sample's subjects are covered so far: the Orangery, house, Archer Pavilion, William III statue, the river, and the people and history around them.
