How to run it

  1. In the app, use the multi-turn chat (AI Chat), not Prompt Lab. Pick the GPU accelerator if offered.
  2. Chat 1: paste Full notes (1,912 words, the same as the browser test). Note the answer and its stats (time to first token, prefill and decode speed).
  3. In the same chat, send each follow-up in turn. These show how fast it is once the notes are loaded.
  4. Chat 2 (new chat): paste Short notes (338 words), what a real question would usually need.
  5. Repeat with a second model if you like. Send me the answers and stats.
